Assignments are balanced: each student is evaluated by the same number of classmates. For small classes, the number is automatically capped at class size minus one. Change this only between cohorts.

How collection works

This version needs no account, hosting, or school network permissions.

1
Instructor creates the class

Save a roster of 4–25 students, choose the peer-review load, and download its class setup JSON.

2
Students complete reviews

Each student opens this HTML file, imports your class setup, evaluates assigned peers, and downloads one completed response file.

3
Instructor combines responses

Collect the JSON response files through an approved channel. Import them together into Instructor results; see averages and narratives, and export CSV.

Privacy & administration: This is a local browser prototype, not a secure or anonymous hosted survey. Response exports contain reviewer identity to check duplicates and completion. Use an approved system and institutional policies for official records or consequential personnel decisions.
Rating fairness: Students may choose N/O — Not observed for behavior they could not assess. N/O is not counted as a score. Compare feedback with instructors' direct observations; avoid using a single peer score as a disciplinary or leadership decision.
